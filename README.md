# Password Generator – Part 1

A simple Android application for generating passwords. This project is the first part of the Password Generator application and provides the basic foundation for building a password-generation tool.

## Features

* Generate passwords
* Simple and user-friendly interface
* Built with Android Studio
* Kotlin-based project
* Uses Gradle Kotlin DSL for project configuration

## Technologies Used

* Kotlin
* Android SDK
* Android Studio
* Gradle

## Project Structure

```text
PasswordGenerator/
├── app/
├── build.gradle.kts
├── gradle.properties
└── settings.gradle.kts
```

## Getting Started

### Clone the repository

```bash
git clone https://github.com/rsdpugeij07/PasswordGenerator-part-1.git
```

### Open the project

1. Open Android Studio.
2. Select **Open**.
3. Navigate to the `PasswordGenerator` project folder.
4. Allow Gradle to sync the project.
5. Run the application on an Android emulator or physical device.

## Requirements

* Android Studio
* JDK
* Android SDK
* Gradle
